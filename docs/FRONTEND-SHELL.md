# FRONTEND-SHELL.md — 前端外壳设计规格（v3：对话 + 上下文感知展示区）

> 版本：v3.0 | 日期：2026-08-07 | 状态：主人定稿（v2 后主人再校正：对话要够大、展示区上下文感知、手动控件保留）
> v3 变更：**两大块**——对话区（操控面，大）+ 展示区（上下文感知，随当前操作切换内容）；手动小控件保留（档位圆点/模型胶囊，点选比命令方便）。

---

## 〇、设计锚点

1. **对话是操控面**：一大块对话区，说话/斜杠命令驱动 Agent。
2. **展示区上下文感知**：一大块展示区，内容随"当前操作"自动切换——不是固定面板堆：
   - 写文章 → 稿纸 + 流式正文（正在写的字实时长出来）
   - 讨论故事发展 → 叙事树 / 方向卡
   - 调整文风 → 相关 skill 列表
   - 审读 → 审读报告（+稿纸内联标记）
3. **手动控件保留（小而精）**：档位圆点、模型胶囊等"点选比说话快"的操作，以小控件常驻；斜杠命令仍可用（老用户快捷方式），两者并存。

**废弃**：氛围滑块（护栏）；四房间抽屉/右侧栏面板堆；Plan/Write 模式切换。

---

## 一、布局（v3）

```
┌────────────────────────────────────────────────┐
│ 顶栏(24px)：书名 · [档位圆点] [模型胶囊] · ⚙      │
├────────────────────────────────────────────────┤
│ 展示区（上下文感知·主角，~60%）                   │
│  写作→稿纸+流式 ｜ 讨论→叙事树 ｜ 调文→skill      │
│  审读→报告(内联标记) ｜ 默认→当前章稿纸            │
├────────────────────────────────────────────────┤
│ 对话区（大块，~40%）                             │
│  [消息流：打字机/工具胶囊/卡片]                  │
│  [输入条 + 斜杠命令菜单]                        │
└────────────────────────────────────────────────┘
```

- **章节树**：对话区上方一条横向章节条（窄，横向滚动），或左侧窄条可折叠——取横向章节条（不占纵向空间，章节标题可点选）。
- **对话区**：大块（约 40% 高度），消息流滚动 + 输入条。常态显示最近消息，不隐藏。
- **展示区**：上下文感知——App 层维护 `display` 状态（paper/tree/skills/check…），由对话事件与用户操作驱动切换。
- **手动控件**（顶栏右侧，小而精）：
  - 档位圆点（0-4，点选即改，hover 显描述）
  - 模型胶囊（点开小菜单选模型/思考强度）
  - 设置 ⚙（斜杠 /settings 或点开）

## 二、展示区上下文感知（机制硬编码：事件→展示形态）

| 触发 | 展示区内容 |
|---|---|
| 默认/选中章节 | 稿纸（TipTap，当前章） |
| Agent 写作中（write_chapter 事件） | 稿纸 + 流式正文预览（正在写的字实时长出来） |
| 对话主题=故事发展（F3：语义或探索事件） | 叙事树视图（节点/锚点/主线/支线） |
| 调整文风（skill 相关对话） | 相关 skill 列表（可开关） |
| `/check` 或审读完成 | 审读报告 + 稿纸内联标记（F3，check offsets） |
| 探索中（explore 事件） | 方向卡/概念卡堆 |

切换逻辑集中在 App 层（一个 display 状态机），各功能域只声明"我要展示什么"，不互相耦合。

## 三、交互补充

- **手动控件与斜杠并存**：档位/模型点选 vs `/agency`/`/model`——同一种操作两种入口（用户习惯任选）。
- **消息卡片**（对话区内）：提问卡/候选卡/报告卡/列表卡——Agent 或命令唤出。
- **选中文本 BubbleMenu**：改写/扩写/续写/润色（F2 后续）。
