## 〇、设计锚点（v2 修订）

1. **写作即对话**：对话是**唯一的操控方式**。用户说话，智能体直接做；不做按钮面板。
2. **平时极简，按需浮现**：常态界面 = 稿纸 + 一条极简输入条。工具/对话框/卡片只在两种时刻出现——**用户唤出**（斜杠/快捷键/选中文本）或 **Agent 唤出**（需要提问/展示结果/请求确认时弹出）。**绝不常驻**。
3. **稿纸是产出物**：视觉主体仍是稿纸（暖纸衬线留白），对话是操控面，两者并重但对话不喧宾夺主。

**废弃（v1 教训，勿复建）**：
- ❌ 氛围滑块（护栏式：工程参数操控创作，违背对话表达）
- ❌ 四房间抽屉控制台 / 右侧栏面板堆（"并列的控制台"是 DESIGN 明令批评的旧形态）
- ❌ Plan/Write 模式切换（Agent 自己理解任务类型，不需用户切模式）

## 一、布局（v2）

```
┌────────────────────────────────────────────────┐
│ 顶栏（20px）：书名 ············· ⚙ 设置          │
├──────────────┬─────────────────────────────────┤
│ 章节树(160px, │ 稿纸（主角·暖纸衬线·大片留白）      │
│  可折叠)      │                                 │
│              ├─────────────────────────────────┤
│              │ 对话（底部展开式·Agent 操作台）     │
│              │  [消息流]（输入时/Agent产出时浮现）  │
│              │  [极简输入条 + 斜杠命令]           │
└──────────────┴─────────────────────────────────┘
```

- **常态**：稿纸全宽主体 + 底部一条极简输入条（高 ~40px，占位"和 AI 说点什么…"）。无消息流、无面板、无按钮堆。
- **对话展开**：用户点击输入/发送后，输入条上方弹出消息流（最近 N 条 + 打字机）。消息流与稿纸同宽（底部弹层），可滚动、可收起。
- **章节树**：窄（160px），可折叠成 32px；折叠后稿纸全屏。
- **设置 ⚙**：斜杠 `/settings` 或顶栏小齿轮呼出（对话内设置卡或极简浮层）。

## 二、交互：一切按需浮现

### 2.1 对话是唯一操控面
用户所有操作都是"说话"：`写第一章`、`把这段改得更紧张`、`查陈渡的设定`、`帮我看看这章`、`导出 epub`。
Agent 智能路由 → 调工具 → 过程在消息流可视化 → 结果以卡片/文本呈现。

### 2.2 斜杠命令 = 用户唤出快捷通道（不是新模式）
输入 `/` 弹出极简命令菜单，选择即执行：
| 命令 | 作用 |
|---|---|
| `/check` | 审读当前章（对话内报告卡 + 稿纸内联标记） |
| `/model` | 模型选择（对话内选项卡） |
| `/agency` | 能动档位（对话内选项卡） |
| `/export` | 导出（txt/md/epub 选项卡） |
| `/upload` | 上传存档（文件选择） |
| `/skills` | 写作技巧列表（对话内卡） |
| `/manual` | 心智条目（对话内卡） |
| `/graph` `/plot` `/plan` | 知识查看（Agent 工具返回卡） |
| `/settings` | 设置浮层 |

命令只是"提前把要说的话说出来"，底层仍是同一对话链路——**没有独立交互面**。

### 2.3 Agent 唤出（事件 → 卡片）
SSE 事件/API 响应 → 消息流内渲染对应卡片（机制硬编码：事件类型→卡片形状；内容 Agent 生成）：
- 工具调用 → 极轻胶囊（`read_setting ✓ 34ms`，可折叠成组）
- 提问（关键歧义点）→ **提问卡**（选项按钮，点选即回复）
- 候选/方向卡 → 卡片堆（点选插入稿纸/确认方向）
- 审读报告 → 报告卡（hard 标红，点定位稿纸）
- 写作完成 → 预览卡（"已写入《第一章》"+ 摘要）

### 2.4 选中文本 → BubbleMenu
选中稿纸文字 → 浮动条（改写/扩写/续写/润色）→ 候选卡入消息流。

### 2.5 快捷键
- `/` 斜杠菜单；`Esc` 收起消息流/关浮层；`Ctrl+\` 章节树
- 无 Ctrl+数字房间（四房间已删）

## 三、视觉（v2 保持纸与墨，更极简）

- 色板不变：暖纸 `#FAF6EF` / 暖墨 `#2D2A26` / 主色黛青 `#3A5A58` / 语义 3 色
- 输入条：纸色细边框圆角，聚焦时主色描边——"一张纸上的写句处"
- 消息流：无卡片化重背景，用极淡纸深色区分；气泡克制
- 卡片：白底细线极淡阴影（同上）
- 动效：消息流/卡片浮现 150-180ms；无表演性动画
- 高级感 = 大量留白 + 克制的色 + 细腻的字体层级 + 轻动效
