## 〇、三个设计锚点（不可违背）

1. **稿纸是主角**：稿纸占视觉重心、最大面积、最少干扰；一切 UI 的存在感低于正文。
2. **操作即表达，打字是最后手段**：点选(0.3s) < 滑块(1s) < 拖拽(2s) < 画布(3s) < 打字(最后手段)。每个组件先问"能不能用操作代替描述"。
3. **功能全保留，全部退后台**：13+ 能力域一个不少，但默认不可见；按需呼出、用完即隐。"你要什么再装什么"从请求参数上升到界面哲学。

## 一、信息架构：四个房间（空间的组织方式）

写作时人的心智自然分成四个"房间"，能力域按心智模型归组（不按技术域）：

| 房间 | 内容 | 心智模型 | 出现频率 |
|---|---|---|---|
| **作品**（常驻） | 章节树、稿纸、对话条（含会话继承 fork） | 我正在写的 | 100% |
| **世界**（抽屉1） | 图谱、设定档、资料、伏笔、计划、角色推演、**叙事树（S59）** | 这本书的世界 | 高 |
| **质量**（抽屉2） | 审读（报告+稿纸内联标记）、规则、统计 | 写得怎么样 | 低 |
| **协作**（抽屉3） | 心智、AI 倾向、写作技巧(skill)、档位 | 我们怎么配合 | 低 |
| **系统**（抽屉4） | 模型、内容化维度、**工作流（S59，默认关）**、扩展工具、导出、上传 | 配置与运维 | 极低 |

**组织决策**：一个"抽屉容器" + 内部标签页，而非 N 个平铺按钮。
- 写作者在"世界"房间内切换图谱/设定/伏笔是同一心智行为（了解我的书），tab 切换 0.1s。
- 顶栏只保留 4 个房间入口 + 1 个探索入口，永不膨胀；新功能 = 新 tab，壳层零改动。

## 二、布局规格

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏（24px，极薄）                                        │
│ 书名 · 探索 ○ ｜ 世界 质量 协作 系统 ｜ · 模型 · 档位 · 连接   │
├───────┬───────────────────────────────────────┬───────────┤
│ 章节树 │                                        │ 写作上下文 │
│ (可折叠│            稿 纸（主角）                 │ (可折叠   │
│  180px)│        暖纸色 · 衬线 · 留白              │  280px)   │
│        │        标题行 · 字数                    │ 氛围滑块   │
│        │                                        │ 能动圆点   │
│        │        审读内联标记（波浪线+hover）       │ 模型/思考  │
│        │        候选裁决浮层（稿纸旁）             │ 改写渐变条 │
│        ├───────────────────────────────────────┤          │
│        │ 对话条（纸边批注，底部 96-140px，可折叠）  │          │
│        │ 会话管理(继承fork) · 输入 · 流式 · 工具胶囊 │          │
└───────┴───────────────────────────────────────┴───────────┘
        抽屉：世界/质量/协作/系统 → 右侧滑出覆盖（640px，内部 tab）
```

### 决策与行为
1. **对话在底部**（纸边批注）：写作即对话是主交互，输入框需要宽度；不压缩稿纸宽度；历史折叠为最近 2-3 条批注，可展开完整记录。
2. **写作上下文在右侧，默认收起**：稿纸全宽是常态；需要时展开（小浮钮/快捷键）。滑块/圆点/模型属于此栏。
3. **章节树在左侧，可折叠**：折叠成 32px 窄条只显示图标。
4. **抽屉覆盖滑出**（非并排）：第三层空间是短暂借用；滑入 180ms + 遮罩轻压暗，主场景不丢失。
5. **探索是一等入口**（顶栏显眼位）：概念卡→方向卡→稿纸是核心循环，种子捕获是唯一入口。
6. **空态**：无章节时中央为"这本书你想写什么？"大输入框，回车即进探索——DESIGN 阶段 0 的唯一入口。
7. **快捷键**：Ctrl+数字 = 1世界 2质量 3协作 4系统；ESC 关抽屉；Ctrl+K 命令面板；Ctrl+\\ 切换章节树；Ctrl+. 切换右侧栏。
8. **布局记忆**：栏宽/折叠状态/抽屉状态持久化 localStorage（Scrivener Layouts 思想，轻量版）。

## 三、视觉系统：纸与墨

**核心隐喻：你不是在用软件，你是在一张好纸上写字。**

### 色板（design tokens，index.css 定义）
| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FAF6EF` | 主背景（暖纸） |
| `--paper-deep` | `#F3EDE1` | 嵌套背景/稿纸边缘 |
| `--ink` | `#2D2A26` | 正文（暖黑） |
| `--ink-2` | `#6B675F` | 次要文字 |
| `--ink-3` | `#A09A8F` | 占位/标签 |
| `--line` | `#E5DFD3` | 分割线/边框 |
| `--accent` | `#3A5A58`（黛青） | **唯一主色**：按钮/选中/焦点 |
| `--ok` / `--warn` / `--danger` | `#3D7A4F` / `#B7791F` / `#B4433C` | 语义 3 色（审读 hard 标红等） |

### 字体与字号
- 正文：`Georgia, "Noto Serif SC", "Songti SC", SimSun, serif`（17px / 行高 1.9）——中文小说正文=宋体是阅读传统；系统字体栈，**零网络依赖**（桌面壳离线可用）。
- UI：系统无衬线栈（13px）；标签 11px；章节标题 22px。
- 数据/数字：tabular-nums。

### 质感与动效（克制）
- 卡片：白底 + 1px 细线 + 极淡阴影 `0 1px 2px rgba(45,42,38,.04)`——"纸上的卡片"而非"浮起来的玻璃"。
- 抽屉滑入 180ms ease-out；卡片浮现 120ms；滑块即时；无表演性动画。
- 聚焦模式（后期）：双击稿纸空白 = 全屏沉浸，UI 淡出。

## 四、交互语言：低摩擦 + 三个升级点

| 交互 | 落点 | 认知成本 | 后端依赖 |
|---|---|---|---|
| 能动性 0-4 级 | 圆点选择器（右侧栏/对话条） | 点选 | 已有 |
| 氛围维度 | 滑块组（拖即语义，数值后端语义化） | 1s | 已有 |
| 探索 | 概念卡点选修正 → 方向卡点选 → 固化入叙事树 | 点选 | 已有（S59 已接树） |
| 审读 | 一键触发 → **稿纸内联标记**（波浪线+hover popover）+ 报告抽屉 | 点选 | **需改动：check 加 offsets** |
| 候选生成 | **裁决浮层**：流式出现 → 接受(一步undo)/拒绝(无痕)/忽略(打字即取消) | 点选 | **需改动：candidates/stream** |
| 改写 | 渐变条：保原味↔均衡↔大幅改 | 1s | 已有 |
| BubbleMenu | 选中段落 → 浮动操作（改写/扩写/续写/润色） | 点选 | 已有端点覆盖（rewrite+candidates） |
| 命令面板 | Ctrl+K：搜章节/切面板/执行动作 | 快捷键 | 零 |
| 会话继承 | 对话条内"继承并新开会话"按钮 + 链条显示 | 点选 | 已有（S58c fork） |
| 插话/取消 | 流式运行时对话条内直接输入/点停止 | 0.3s | 已有 |

### 信号上报（解耦原则）
所有产生对齐信号的操作（选择/接受/修改/删除/调级）静默上报 `/api/signals`——前端只做动作，后端提炼，前端不感知。**工具执行状态**在对话气泡内以极轻胶囊显示（`read_chapter ✓ 23ms`），不打断。

## 五、架构：抽屉注册表（可扩展性承诺）

```
新增一个功能 = 新增一个 feature 域 + 注册表加一行 + 抽屉加一个 tab
壳层（布局/顶栏/抽屉容器/快捷键）零改动
```

- **抽屉注册表**（`components/drawers/registry.ts`）：`{ id, room, label, icon, shortcut, render }`——四房间 tab 由注册表驱动，标签顺序/快捷键是数据。
- **api 层**唯一出入口（apiFetch 保留），每域一模块；后端加端点 = 加一个模块。
- **store 域隔离**：对话只管对话、章节只管章节、心智只管心智……互不耦合（延续现有模式）。
- **SSE 引擎**：`api/chat.ts` 保留升级（chat/stream 已解析；candidates/stream 复用同一解析器）。
