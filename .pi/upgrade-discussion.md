## 〇、讨论背景

- 项目：AnySpark v3.2.5，AI 小说创作引擎（Agent 自主循环 + 工具 + SQLite 图谱 + React 前端）
- 升级方向：**功能升级 + 架构升级 + 美学升级**（美学暂缓——未来换风格容易，关键在功能与交互）
- 另一个智能在负责遗留债务收尾（L 系列：mypy 清零/覆盖率/前端拆分），与本升级并行不冲突
- 核心锚点：**本项目最终最直接目的是 AI 写小说**

## 一、智能体设计原则（已达成，共 5 条）

1. **易用** — 用户上手成本趋近于零
2. **简洁解耦去限制化** — 不过多用人类规则限制智能体发挥；参考 pi 设计哲学（核心极简、功能外置、默认强大）
3. **平滑性** — 从"只有灵感的人"到"有完整规划的作家"都能用好，能力随使用浮现
4. **深度对齐** — 沟通成本不能大于写作成本；否则不如自己写
5. **极简方法论（最新确立）** — 最文本、最简单的方法优先；相信模型能力；自然语言承载；不过度工程。所有设计过"极简审查"
6. **逐步展开（交流基础假设）** — 无论用户脑中信息多少（只有灵感 or 完整骨架），人类交流总是**逐步、一句一句展开**的，不会一次性给出全部。推论：
   - AI 不期待用户一次给全信息，也不在用户未展开时自行脑补（抢跑）
   - AI 的每次输出都是"下一轮对话的准备"——信息交换是**小块、频繁、双向**的，不是大块一次性
   - 用户展开密度本身就是信号：说得细=图景清晰（AI 多执行），说得模糊=还在酝酿（AI 多引导）
   - 能动性 = 跟随展开节奏

## 二、对大模型与写作本质的认识（已达成）

- 大模型是**概率探索器**：默认走最大概率路径 → 高概率区 = 平庸区
- 优秀作品位于**奇异点**（低概率高价值区），默认采样走不到
- **抽卡（Best-of-N）收益有限**：只能改善平庸区内的排序，到不了奇异区
- 所以写作智能体需要的是**航向系统**（探索指引），不是**护栏**（禁令/模板/扣分）：
  - 死约束（禁令、模板、AI味扫描扣分）→ 把模型钉在平庸区，应退役
  - 活约束（意图、情感目标、读者体验、张力方向）→ 剪枝搜索空间，让探索聚焦奇异区
- 写作起点是**种子**：用户脑中已有新颖概念/激动场景 → 人机深度结合，非纯自主探索
- **双向黑盒是摩擦根源**：人不知道 AI 倾向（换模型还会变）、AI 不知道人的种子
  - 解决一：可观测的探索过程（用户能看到 AI 候选/理由/迭代，建立预期）
  - 解决二：**AI 倾向档案**——AI 主动暴露自己当前的倾向（"我这个模型写对话偏克制"），让用户能预测它，从而敢放手
- **体验目标：摩擦前置且递减**（北极星指标）
  - 现状：用户下指令→AI 闷头写→评审挑错→返工（事后纠错，摩擦峰值在最后）
  - 目标：种子交换→方向对齐→可观测写作（事前对齐，摩擦前置且递减）
  - 所有设计取舍以此为准：好交互 = 早期花小成本对齐，后期零返工；坏交互 = 前期不确认，后期大返工

## 三、功能规划（已达成初步共识）

### 决策标准：两方价值
> 用户不看 + 智能体也不用 = 删；**只要一方有较大价值就留**（人机结合项目，从两方考虑）

### 去留清单

| 功能 | 用户价值 | AI 价值 | 决策 |
|------|---------|---------|------|
| 叙事统计（Stats/Pacing/Heatmap/Metrics） | ✗ 作家不看 | ✗ 不需要 | 🔴 删 |
| AI 味扫描 | ✗ | ✗ 死规则反伤质量 | 🔴 删 |
| 记忆面板（手工分类表单） | ✗ 不想管理 | ✗ 对齐系统不需要 | 🔴 删（系统改造为对齐） |
| 知识库 | ○ 偶尔确认设定 | ✅ 写作一致性 | 🟢 留，退后台（AI 事实源） |
| 稿纸/对话/大纲/伏笔/剧情链/章节历史 | ✅ 核心 | ✅ | 🟢 留 |
| 资料库 | ✅ 扔素材 | ✅ 消化后参考 | 🟢 留，**补消化能力** |
| 文风/参考书 | ✅ | ✅ | 🟢 留 |
| 时间线/地图/灵感盒/推演 | ○ 部分类型刚需 | ○ | 🟡 降权，不进主导航 |

### 现状诊断（记录）
- 大量功能实现程度不一致：资料库、记忆系统几乎未实现
- 记忆系统现状 = 表单工具（手动分类偏好），非智能能力
- 资料库现状 = 存储 CRUD，无消化无关联

## 四、核心机制设计（已达成方向，细节待定）

### 1. 探索-判别双循环（写作机制）
```
用户一句话（意图）→ 航向解析（奇异点坐标大致在哪）
  → 多路探索（N 个差异化候选：换叙事策略/切入点/结构/文风偏移）
  → 判别（哪个最接近航向：LLM 判别器 + 人类在环选择）
  → 迭代收敛（选中方向 → 探索细节 → 再判别 → 收敛）
```
- 用户不是指挥者，是**判别器**（选择比描述容易）
- 每次选择同时写进用户模型（对齐）

### 2. 能动性协议（AI 做多少）
- 五级协议：0 只听写 / 1 执行+填肉 / 2 补全但标注 / 3 建议扩展 / 4 自主发挥
- AI 每轮可声明级别，用户一键点选修正；反馈自动调节（删=降级，接受=升级）
- 用户信息是**逐步展开**的 → AI 跟展开节奏走：种子阶段多问少做，方向确认后多做
- 长期看：能动性应是**心智模型的输出**而非独立旋钮——合作久了 AI 自然知道用户要什么程度，显式声明退场（只在冷启动/高不确定时出现）
- 隐式信号：修改频率、接受率、沉默、删改内容

### 3. 对齐系统（替代记忆系统）
- **路线选择：对齐优于记忆**。记忆路线有本质困难（存储-检索完备性无法达到，机械机制到不了人类记忆水平）；对齐追求"方向正确"而非"完整记录"，可持续逼近，且有容错性（错了纠正即新信号）
- 一条偏好陈述可指导几百次写作；百条历史记录每条只对特定时刻有用 → 信息密度决定对齐更优
- **用户模型 = 可解释偏好档案**（自然语言短句 + 来源 + 置信度 + 活跃度），模型无关（新模型可读，换模型不丢）
- **对齐信号全部来自操作**（选择/修改/删除/反馈），零打字成本，无表单
- 注入方式：每次会话注入，类似 pi 的 AGENTS.md
- 第一批信号来源（建议）：选择信号（方向卡选择）+ 修改信号（编辑器删改）
- **AI 的提问 = 不确定性信号**：只在"不知道该做什么"时才问，且问的是**关键歧义点**（"主角此时是恐惧还是渴望？"）而非泛泛问卷——提问从"烦人"变"必要"
- **提问频率 = 对齐进展的可视化**：用户看到的不是"AI 老问问题"，而是"AI 越问越少"——默契度增长本身就是产品体验

### 4. 低摩擦交互层（操作式表达）
- 打字 < 说话 < 脑内思考 → 把"描述"变"操作"
- 交互通道分层：点选(0.3s) → 滑块/旋钮(1s) → 拖拽(2s) → 画布操作(3s) → 打字(最后手段)
- 组件：能动性选择器、方向诠释卡、氛围滑块组、场景拼图板、候选卡堆、改写渐变条
- 每个操作 = 结构化对齐信号（操作即语义——打字需要解析语义，操作本身就是语义）
- **共同对象原则**：双方在同一对象上交流（概念卡/结构图/候选卡），而不是来回打字传达——卡片是"共享的稿纸"

### 5. 前端空间设计（美学方向，美术暂缓）
- 核心：把"并列的控制台"变成"有主角的创作台"——稿纸为主角，功能全保留
- 三层空间：稿纸（第一层，视觉主体）/ 写作上下文-候选卡·氛围·能动性（第二层，轻量浮现）/ 设定工具抽屉-知识·角色·时间线等（第三层，按需呼出，保留 Ctrl+数字）
- 对话从聊天窗口降为纸边批注；视觉收敛（荧光色→1主色+3语义色；字号层级重建；质感动效）
- 现有工程资产：19 面板分组导航、分屏、命令面板、快捷键、focusMode——保留利用

### 6. 结构模式模板（三层体系，讨论收敛）
- **核心认知**：大模型本身就是"不稳定的库"——训练数据内化了海量类型学知识（废柴流/升级流/双线/悬疑揭示/三幕/英雄之旅…），不需要从零外部建库
- **三层体系**：
  - L1 模型内化知识：免费、即时，解决"有没有"
  - L2 开发者默认库：精选少量高质量模式，解决个人用户大部分问题（内容工作是编辑能力非编程能力）
  - L3 进阶外部库：用户导入/平台库/社区共享——**商业化方向**（B 端平台有海量数据+版权协商简单，是深水区；C 端 L1+L2 够用）
- **统合方法：自然语言是唯一介质**——三层模式都以自然语言描述存在（+轻量元数据：粒度/位置/功能/来源，仅用于筛选注入）；模型自己读、自己融合、自己组合。不建组合引擎/匹配规则/冲突检测（都是强制护栏）
- **模板四要素元数据**：{ 粒度(全书/卷/章/场景/段落), 位置(开局/发展/高潮/结局), 功能(铺垫/主线/悬念/爽点/情感), 可变参数 }
- **边界（锁死）**：模板只做"探索方向的生成器"（粗粒度航向），绝不做"内容的框架"（填空=套路文，且模板被大量使用后自身变成新平庸区）；模板是起点，变体才是目标
- **稳定性**：模型内化知识每次生成会漂移 → 用户确认过的方向固化为自然语言记录（进项目档案/用户模型），可复现可引用；固化时机=用户确认，模板机制与对齐机制在此合一
- **提取能力边界**：LLM 能做"鉴定"（套人类已命名类型学框架+提取量化特征——网文社区已完成的命名是公共知识），做不了"发明"（发现人类未命名的新奇异结构）；人类提供分类学，LLM 做标本鉴定
- **交互红利：流派术语=共同语言**——候选卡直接用术语标注（"废柴流开局·反差铺垫"），懂网文的作者秒懂，术语卡代替描述，降低沟通成本
- **架构含义**：模式库抽象为独立层，数据源可插拔（模型内存/默认库/用户导入/平台库）
- **探索方向三来源混合场（模板不独占）**：探索候选必须混合三个来源，否则小众/原创型用户被隐形模板墙框死：
  - ① 模板派生：从三层模板体系生成的方向（服务小白/快速起步）
  - ② 作品内在生长：完全从种子+已有内容自然推导，不走任何模板（服务原创性需求；纯靠模型对这部作品的理解，不依赖库）
  - ③ 用户指导：用户脑中非常规约束直接作为航向（"没有情节只有氛围"）（服务专家/有明确想法的人）
  - 候选卡永远混合三来源（例：4 张卡 = 2 模板 + 1 自由生长 + 1 用户直觉）；用户选模板还是选自由卡 → 对齐信号 → 未来混合比例自动调整（模板占比=用户模型的输出）
  - 一句话：**模板是探索的脚手架之一，不是道路本身；道路由三来源共同铺成**

### 7. 多智能体探索（探索-判别的实现形态）
- **动机**：同上下文多选项存在伪多样性（一个模型给 4 个选项会被自己第一个思路锚定、向中间收敛）；上下文隔离 → 真多样性（multi-prompt sampling / ensemble 有理论支撑）
- **现有落点**：现有子 Agent 系统（5 种类型、独立上下文派生）就是天然基础，不是新造架构
- **流程**：
  ```
  [意图理解者] 理解种子+用户要求 → 对齐确认（先给用户看，摩擦前置最便宜的纠错点）
        ↓ 确认后
  [探索策略集] 主 Agent 定义差异化分派（按叙事维度/模板/自由/用户指导分派）
        ↓ 并行（asyncio.gather，轻量上下文）
  [探索者 ×3-4] 各自产出方向卡（带术语标注）
        ↓
  [用户判别] 选/杂交 → 反馈信号 → 定向再探索（多轮）
        ↓
  [固化] 选中方向落盘进项目档案
  ```
- **8 项约束（讨论确认）**：
  1. 成本控制：探索者用轻量上下文（种子+关键设定摘要+方向指令，不带全量图谱）；并行调用时间≈单次；探索层可跑 Flash，Pro 留给写作
  2. 轻量优先：探索者多数是单次 LLM 调用，不需要完整 while-true 循环+工具；只有需查资料的探索者才给工具（避免过度工程）
  3. 多样性不自动保证：主 Agent 先定义探索策略集（情节驱动/角色驱动/氛围驱动/结构实验/模板/自由/用户指导…），每个探索者拿不同维度指令
  4. 意图理解者产出物是"对齐确认"而非方向——先确认理解再放探索者跑（两阶段：意图确认→方向探索）
  5. 多轮循环：单轮 4 卡可能都不对，用户要的是杂交（"A 设定+B 结构"）→ 定向再探索
  6. 选中方向结构化摘要固化进项目档案（探索者隔离，主 Agent 需要记住方向细节）
  7. 轻量上下文必须含"已固化设定约束"（一句级：女主=医者）——探索自由但不得撞已固化的墙
  8. 展示顺序效应：多卡随机排序/分组展示，避免位置偏见污染对齐信号

## 六、T2：种子→作品完整交互流程（已确认）

> 原则贯穿：摩擦前置（每步先对齐再前进）、操作即表达（打字最后手段）、按需深入（用户到哪层探索到哪层）、展开密度即信号（输入越完整，低级探索越自动跳过）
> 核心循环只有三个对象：**概念卡（理解）→ 方向卡（选择）→ 稿纸（产出）**，其余都是变形

### 阶段 0 · 进入（几秒）
- 唯一入口："这本书你想写什么？"——一句话 / 粘贴完整大纲（自动消化，不强制分卷建章）
- 平滑性：入口只有一个，能力随输入密度自动分级
- **专家路径**：输入密度高（粘贴完整骨架）→ 自动跳过低级探索，直接进图谱/写作

### 阶段 1 · 种子捕获（第一次对齐，1-2 分钟）
- 用户自由说种子（画面/概念/情绪/设定都行）
- AI 不立即干活：① 复述成**概念卡**（画面核心/情绪基调/类型直觉/种子位置(开篇?/高潮?/结局?)，可点选修正）② 只问 2-3 个**关键歧义点**（AI 提问=不确定性信号，只问影响方向的问题，如"两人是熟悉还是陌生？"）
- 概念卡=共同对象，双方在它上面交流；种子位置确认（创作动力≠结构支点）；能动性默认 0-1 级

### 阶段 2 · 方向探索（几分钟）
- 多智能体并行（意图理解者→探索策略集→探索者×3-4 轻量），产出**混合三来源**方向卡（2 模板+1 自由生长+1 用户直觉，带术语标注）
- 用户判别：选它 / 感兴趣展开（定向再探索多轮）/ 再来一批；**"我已有想法直接写"出口**
- 选中方向→结构化摘要**固化进项目档案**（含已固化设定约束，后续探索不得撞墙）
- 对齐信号：选模板 vs 自由卡 → 学习用户类型 → 未来混合比例自动调整

### 阶段 3 · 关键点图谱（作品级规划，可选深入）
- AI 基于概念卡+方向生成图谱草案（主线冲突/角色弧/情感核/世界规则/情绪峰值/伏笔/节奏——网状非大纲）
- 用户操作：增/删/改/标"我在意/不需要"——操作即对齐信号，关注点跟随在此学到
- **图谱=跨章长期记忆**：每章写作时注入其当前状态（哪些推进/哪些没收），从规划工具升级为活的长期记忆；可演化非一次性工程
- 不强制：小白可跳过直接写作，专家可深耕；分层探索（作品级→章级→场景级，用户说到哪层探索到哪层）

### 阶段 4 · 按需深入
- "我想写第一章"→只探索第一章；"理下第 3-5 章"→卷级；"直接写"→进稿纸。不为未写的部分付探索成本

### 阶段 5 · 写作（主体，稿纸为中心）
- 用户在写：AI 后台工作（记住设定/一致性检查，不打扰）
- "你写这段"：声明级 3-4 → **方向声明**（"我准备写：主角推开玻璃…"）→ 用户 0.5s 确认/调级 → 探索-判别生成 → 候选卡 → 选
- **方向声明限定**：只在方向不确定/能动级别变化时出现，确认后连续写作不再重复确认（默许=授权）
- 卡壳：建议卡（可拖入稿纸或丢弃，从不直接改稿）；选中段落要改：候选改写卡堆+渐变条（保原味↔大幅改）
- 连贯性后台化：知识库/设定约束 AI 自动维护；撞已固化设定→温和提醒卡（非弹窗打断）

### 阶段 6 · 一章完成（轻量收尾）
- 自动：更新关键点图谱（哪些推进了）+ 一致性摘要卡（一句话非强制）+ 下一章衔接提示（"建议推进角色弧，展开吗？"）
- 不自动评审：评审降为按需增强包，用户喊"帮我看看这章"才出现（重构为判别器：选方向不挑毛病）

### 贯穿：对齐积累
- 每次点选/修改/删除/标注/调级→对齐信号→用户模型更新→注入后续全部探索与写作；信号带置信度（单次操作不产生强结论）；提问频率递减=默契度增长的可视化
