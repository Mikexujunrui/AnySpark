## 一、v4 是什么（30 秒版）

AnySpark 正在从"规则密集的控制台"升级为"极简创作台"：**写作即对话，稿纸为主角，AI 靠探索与对齐而非护栏**。三大方向：功能升级 / 架构升级 / 美学升级（美学暂缓）。

六条设计原则：易用、去限制化（参考 pi 哲学：核心极简、功能外置）、平滑性、深度对齐、极简方法论（相信模型、自然语言承载、不过度工程）、逐步展开（用户信息小块渐进，AI 跟节奏）。

## 二、已确认的结论（执行时依据）

### 功能去留（两方价值标准：用户不看 + AI 不用 = 删）

| 决策 | 功能 |
|------|------|
| 🔴 删 | 叙事统计（StatsDashboard / PacingCurve / CharacterHeatmap / WorldbuildingMetrics）、AI 味扫描、记忆表单面板 |
| 🟢 留（核心） | 稿纸编辑器、对话、大纲/分卷、伏笔、剧情链改写、章节历史 |
| 🟢 留（退后台） | 知识库（AI 事实源，自动维护，用户零管理）、资料库（补消化能力） |
| 🟡 降权 | 时间线 / 地图 / 灵感盒 / 推演（不进主导航，部分类型刚需） |
| 🔻 降为可选增强 | 评审团（重构为判别器）、Autopilot、工作流、Skill、创作宪法、叙事约束、文风注入 |

### 七大核心机制（已定方向）
1. 探索-判别双循环（用户是判别器，不是指挥者）
2. 能动性协议（0-4 级，AI 声明+用户点选+反馈自动调节）
3. 对齐系统（替代记忆：可解释偏好档案，信号全来自操作）
4. 低摩擦交互层（点选→滑块→拖拽→画布→打字，打字是最后手段）
5. 创作台空间（稿纸主角，三层空间，功能全保留）
6. 结构模式模板（三层：模型内存/默认库/外部库；自然语言唯一介质；模板只做探索航向）
7. 多智能体探索（意图理解→策略集→并行探索者→用户判别→固化；复用现有子 Agent 系统）

### T2 完整流程（已确认）
六阶段：进入 → 种子捕获（概念卡）→ 方向探索（方向卡）→ 关键点图谱（可选）→ 按需深入 → 写作（稿纸）→ 一章收尾。核心三对象：**概念卡 → 方向卡 → 稿纸**。详见讨论纪要第六节。
